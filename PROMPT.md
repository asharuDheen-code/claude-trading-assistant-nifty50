# The one prompt

Open Claude Code inside this folder and paste:

```
Nifty 50 scan ചെയ്ത് ഇന്നത്തെ opening-range breakouts കണ്ടെത്ത്. എന്റെ capital ₹1,00,000, risk 1%.
ഓരോന്നിനും entry, stop, target, എത്ര share എന്ന് പറ. 10,000 replays run ചെയ്ത് result Malayalam-ൽ ചുരുക്കി പറഞ്ഞുതാ.
```

English:

```
Scan the Nifty 50 for today's opening-range breakouts. My capital is ₹1,00,000 and I risk 1% per trade.
For each one give entry, stop, target and position size, run 10,000 replays and summarise the result in English.
```

Change the capital and risk to yours. Claude uses the `nifty50-trading-assistant` skill in `.claude/skills/`.

⚠️ Not financial advice. Educational tool only. Trading involves risk of loss.
